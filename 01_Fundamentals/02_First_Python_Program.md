## What is `print()`?

`print()` is a built-in Python function used to display information in the output.

For example:

```python
print("Hello Python")
```

Python displays:

```text
Hello Python
```

The text inside quotation marks is called a **string**.

I will learn more about strings later, but for now I only need to understand that Python can display text using `print()`.
